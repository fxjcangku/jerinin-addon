# 模块说明 / Module Guide

## ⚔️ 战斗模块

### 传送重锤 (TpMace)
3D 分段传送至目标上方高空，随后自由落体触发重锤伤害。
- 支持图腾绕过检测
- 内置目标位置预测
- 可配置安全扫描范围

### 新TP重锤 (XinTpMace)
预测目标未来移动坐标，精准传送后通过多高度 VClip 连续重锤。
- 更高命中率
- 支持连续多次重锤

### 长矛杀戮 (SpearKill)
自动锁定最近玩家并切换长矛发动攻击。
- 直接攻击模式
- 突进冲刺模式

### 破盾重锤 (MaceBreakerPro)
实时检测目标是否举盾，自动切换斧头破盾后追击。

### 白名单 (WhiteList)
管理攻击目标名单，仅对名单内玩家触发战斗模块。

---

## 🚀 移动模块

### 垂直上升 (VerticalRise)
分段垂直发包快速上升，可配置每段高度与速度间隔。

### 自动落地水 (AutoWaterMLG)
检测高空坠落或玩家着火状态，自动放置水桶救命，落地后自动收回。

---

## 🤖 自动化模块

### 星露谷农业助手
识别服务器资源包中的自定义作物，支持作物筛选、成熟扫描、路线规划，以及可选的收获、补种、库存和容器辅助。

### 服务器登入助手
面向需要 `/login` 或 `/register` 的离线模式服务器，支持服务器匹配、离线昵称匹配、登录后指令、资源包处理和断线重连。密码只保存在本地配置。

### 附魔交易所 (AutoLibrarian)
全自动附魔刷新流程：
1. Baritone 寻路至附近村民
2. 检测并清除讲台障碍
3. 放置讲台刷新交易
4. 读取交易列表
5. 匹配目标附魔后自动购买

> 需要安装 Baritone 寻路前置

### 圆石出售 (CobbleSeller)
背包圆石数量达到阈值时自动出售，附带防掉线心跳和 HUD 实时库存显示。
