# Slimefun 自动合成助手

> 基于 JsMacros 的粘液科技配方读取、材料计算与自动合成工具。

## 主要功能

- 从粘液科技指南读取并保存配方
- 根据目标物品自动计算材料依赖和合成顺序
- 扫描附近工作站与存储容器
- 自动补充缺失材料并执行合成
- 在 HUD 中显示制作列表、缺失材料和合成队列
- 使用黑名单排除不希望自动处理的配方
- 通过网页管理器编辑和导出工作站配置

## 必装前置 Mod

粘液助手是 JsMacros 使用的 JavaScript 脚本，**不是可以直接放进 `mods` 文件夹的 Mod**。运行本项目必须先在 Minecraft 客户端安装 JsMacros：

- [JsMacros 官方 GitHub Releases](https://github.com/JsMacros/JsMacros/releases)
- [JsMacros 官方 Modrinth 页面](https://modrinth.com/mod/jsmacros/versions)
- [JsMacros 官方文档](https://jsmacros.wagyourtail.xyz/)

下载时必须同时匹配 Minecraft 版本和 Mod 加载器。Fabric 客户端选择 Fabric 文件，Forge 客户端选择 Forge 文件；不匹配的 JAR 可能无法加载或导致游戏启动失败。

### 安装 JsMacros

1. 确认当前 Minecraft 实例使用的游戏版本以及 Fabric/Forge 加载器。
2. 从上方官方地址下载完全匹配的 JsMacros `.jar`。
3. 将该 JAR 放进当前 Minecraft 实例的 `mods` 文件夹。
4. 启动游戏，并确认可以打开 JsMacros 的配置或宏界面。

只有完成以上步骤后，客户端才具备导入和运行 `.js` 脚本的能力。

## 安装粘液助手

1. 从项目 [Releases](https://github.com/fxjcangku/jerinin-addon/releases/tag/v4.5.4) 下载 `V4.5.4.zip`。
2. 解压 ZIP，并保留完整的“粘液助手”文件夹结构。
3. 从游戏内 JsMacros 界面打开脚本/宏目录，避免误放到其他 Minecraft 实例。
4. 将整个“粘液助手”文件夹放入该目录，不要只复制 `粘液助手 V4.5.4.js`。
5. 确认 JS 文件旁边存在 `config` 和 `html` 目录，以及其中的配置文件。
6. 在 JsMacros 中新建按键宏或事件，脚本语言选择 JavaScript，文件选择 `粘液助手/粘液助手 V4.5.4.js`。
7. 保存宏并设置运行按键。

## 使用方法

### 启动脚本

1. 进入支持粘液科技的服务器。
2. 将粘液科技指南放在副手。
3. 按下为粘液助手绑定的宏按键。
4. 脚本会加载配置、初始化粘液指南、注册 HUD 和事件监听。
5. 聊天栏出现“脚本已启动”，且 HUD 显示制作列表、材料列表和合成队列，即表示启动成功。

### 停止脚本

脚本运行期间再次执行同一个脚本，即可请求停止。若脚本没有正常停止，可再次执行并按照游戏内提示强制关闭旧上下文。

### 读取配方

打开粘液科技指南后，脚本会在支持的界面中提供以下操作：

- **读取配方**：读取当前分类中的可用配方
- **读取当前配方**：只保存当前展示的配方
- **添加到黑名单**：阻止指定物品参与自动合成
- **从黑名单移除**：恢复指定物品的自动合成

### 自动合成

1. 在指南配方页面选择需要制作的物品和数量。
2. 确认 HUD 显示的材料列表和合成队列正确。
3. 关闭指南界面以开始自动合成。
4. 脚本会扫描附近容器和工作站，取出材料并依次合成。

首次使用时请先用少量普通材料测试，确认服务器的菜单布局、物品 ID 和工作站配置与脚本兼容。

## 文件结构

```text
粘液助手/
├─ 粘液助手 V4.5.4.js          主程序脚本
├─ 使用说明.md                 使用说明
├─ config/
│  ├─ 配方.json                已读取的配方
│  ├─ 工作站.json              工作站结构与槽位配置
│  └─ 黑名单.json              禁止自动合成的物品
└─ html/
   ├─ 工作站配置管理器.html    工作站配置编辑器
   ├─ js/                      页面逻辑与本地依赖
   └─ css/                     页面样式
```

## 工作站配置管理器

打开 `html/工作站配置管理器.html` 可以编辑工作站配置。

1. 使用“导入配置”选择现有的 `工作站.json`。
2. 添加、编辑或删除工作站。
3. 使用“下载 JSON”导出新的配置。
4. 将导出的文件替换到 `config/工作站.json`。
5. 重新启动脚本以加载新配置。

网页管理器不会直接修改脚本目录中的配置文件，需要手动导出并替换。请勿导入来源不明的 JSON 配置。

## 兼容性说明

- 原说明要求 JsMacros 1.9.2+、Minecraft 1.20.1+。
- 新版 Minecraft 必须使用对应版本的 JsMacros，不能混用不同游戏版本的模组文件。
- 不同服务器可能安装不同版本的 Slimefun 或附属插件，GUI 标题、槽位、物品 ID 和工作站结构可能不同。
- 如果配方读取错位、工作站无法识别或自动点击位置错误，应立即停止脚本并调整配置。
- 使用自动操作前请确认服务器规则允许此类客户端脚本。

## 注意事项

- 配置文件必须是有效的 JSON 格式。
- 配方 ID 和工作站 ID 必须与服务器中的实际 ID 一致。
- 自动合成前应预留足够的背包空间。
- 首次测试不要使用贵重材料，也不要在装满重要物品的仓库附近运行。
- 运行日志保存在 `logs/slimefun-helper.log`，每次启动会清理旧日志。

## 常见问题

### 脚本无法启动

- 检查 JsMacros 是否与当前 Minecraft 版本匹配。
- 确认副手持有粘液科技指南。
- 查看游戏聊天提示和 `logs/slimefun-helper.log`。

### 配置无法加载

- 检查三个 JSON 文件是否存在且格式正确。
- 确认整个文件夹已放入 JsMacros 脚本目录。
- 检查文件名是否保持为 `配方.json`、`工作站.json` 和 `黑名单.json`。

### 读取不到配方

- 确认当前界面是粘液科技指南的配方页面。
- 检查服务器是否修改了指南布局或菜单物品 ID。
- 尝试先使用“读取当前配方”测试单个配方。

### 无法识别工作站

- 确认工作站位于玩家交互范围内。
- 检查工作站结构、方块 ID、GUI 名称和槽位配置。
- 服务器使用不同附属版本时，需要重新制作对应的工作站配置。

### 脚本没有响应

- 再次运行脚本以请求停止。
- 根据提示再次执行，强制关闭旧脚本上下文。
- 仍无法恢复时，重启 Minecraft 后再测试。
