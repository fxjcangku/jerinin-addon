# 星露谷农业资料使用说明

这组资料整理自服务器自定义作物的识别结果，用于查阅作物分类、成熟状态和种子编号。

## 编号说明

- `序号`：公开资料中的排列编号，不是游戏内部编号。
- `作物 ID`：通常写作 `customcrops:内部名称`。
- `成熟状态号`：`minecraft:tripwire` 的状态编码，范围为 0–127。
- `种子物品`：自定义种子通常使用 `minecraft:paper`。
- `种子 CMD`：通过 CustomModelData 区分不同种子。

## 分类

- 蔬菜
- 水果
- 菌菇
- 经济作物
- 特殊

分类号固定为：`01` 蔬菜、`02` 水果、`03` 菌菇、`04` 经济作物、`05` 特殊。

## 识别规则

自定义作物的状态号由以下属性编码：

```text
64×attached + 32×east + 16×north + 8×south + 4×disarmed + 2×west + powered
```

红包的成熟状态比较特殊，阶段会从 `123` 到 `127`，最后回到 `0`，不能只按数字大小判断成熟。

苹果的作物 ID 和成熟状态已经记录，但目前没有确认对应种子编号，因此表格中标记为“未确认”，请不要据此配置自动补种。

这些文件是独立整理的分析资料，不包含服务器资源包原档、第三方材质或核心实现。
